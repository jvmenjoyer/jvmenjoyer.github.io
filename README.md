# Athly — дневник тренировок

PWA-дневник тренировок для iPhone: база упражнений с фото, готовые и свои
программы, учёт подходов, веса, повторений, RPE, суперсетов и разминочных
подходов. Работает офлайн, данные хранятся на устройстве.

## Возможности

- **876 упражнений** с двумя фото (public domain, free-exercise-db), поиск и
  фильтры по группам мышц и инвентарю. Названия на русском (английские сохранены
  для поиска), техника — на русском.
- **AI-тренер Athly Coach** (DeepSeek Flash через Cloudflare Worker): разбор
  тренировок, рекордов и прогресса, составление программ, запись замеров и
  запуск тренировок. Все действия — с подтверждением в чате.
- **Программы**: Full Body 3×, Upper/Lower 4×, Push/Pull/Legs 6×, Bro Split 5×,
  StrongLifts 5×5 + конструктор своих программ.
- **Тренировка**: упражнения из программы или с нуля, подходы (вес × повторы),
  RPE 1–10, разминочные подходы, метки суперсетов, заметки, **таймер отдыха** с
  автостартом, звуком и уведомлением.
- **Следующая тренировка**: веса подставляются по последним результатам
  (автопрогрессия +/−2,5 кг, учёт RPE и пропусков), день программы выбирается
  автоматически.
- **Автобэкап**: снимок данных раз в сутки и после тренировки, восстановление из
  настроек; плюс экспорт/импорт JSON.
- **Калькуляторы**: 1ПМ, блины на штангу, разминочные подходы.
- **Календарь** и история, повтор тренировки.
- **Замеры**: вес тела, процент жира и обхваты + график.
- **Прогресс**: тоннаж по неделям, объём по группам мышц, личные рекорды.
- **Уведомления**: окончание отдыха, если приложение свёрнуто.
- **Экспорт/импорт JSON**, данные только на телефоне.
- **PWA**: установка на домашний экран, офлайн-режим.

## Стек

React 19 + TypeScript, Vite, Tailwind CSS 4, Dexie (IndexedDB), Zustand,
Recharts, Zod, date-fns, vite-plugin-pwa. Тесты — Vitest, смоук — Playwright.

## База упражнений

- Источник: [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (The Unlicense, public domain).
- 876 упражнений, 1746 фото. Фото сжаты в WebP 480px (~22 МБ на всё).
- Скрипт подготовки: `scripts/prepare-exercises.mjs` — скачивает JSON и фото,
  сжимает их и кладёт в `public/exercises/` и `public/data/exercises.json`.
- Перевод: `scripts/translate-exercises.py` — локальная модель Argos en→ru,
  кэш переводов в `scripts/data/`. Запуск через `uv`:

```bash
uv run --python 3.12 --with argostranslate python scripts/translate-exercises.py
```

Перевод автоматический; ключевые упражнения можно поправить вручную в
`public/data/exercises.json`.

## Деплой

Приложение раздаётся с GitHub Pages (ветка `gh-pages` репозитория
`jvmenjoyer/jvmenjoyer.github.io`).

```bash
npm run deploy
```

Скрипт `scripts/deploy-pages.mjs` собирает проект, копирует `dist` в ветку
`gh-pages` и делает force-push. Нужен авторизованный GitHub CLI (`gh auth login`).

> Netlify не используется: на текущем соединении он обрывает большие файлы
> (JS/JSON) после ~20 КБ. `netlify.toml` оставлен как альтернатива.

### AI-тренер: Cloudflare Worker

Прокси лежит в `worker/`, ключ DeepSeek хранится только в секретах Cloudflare.

```bash
npx wrangler login
npm run worker:secrets   # берёт DEEPSEEK_API_KEY и ATHLY_ACCESS_CODE из .env.local
npm run worker:deploy
```

Worker: `https://athly-coach.jvmenjoyer.workers.dev`.

В приложении: **Тренер → Настроить** → вставить `ATHLY_ACCESS_CODE` из
`.env.local` → «Проверить» → «Сохранить». Код хранится только в браузере
телефона, в репозиторий не попадает.

### Перевод упражнений

```bash
npm run translate
```

Скрипт `scripts/translate-deepseek.mjs` переводит названия из
`public/data/exercises.json` через DeepSeek, сохраняет кэш в `scripts/data/` и
поднимает версию каталога, чтобы приложение перечитало базу.

### Установка на iPhone

1. Откройте ссылку в Safari.
2. «Поделиться» → «На экран Домой».
3. Откройте с иконки и дайте один раз загрузиться онлайн — дальше офлайн.
   Тренеру интернет нужен всегда.

## Ограничения

- Только килограммы и русский интерфейс.
- Нет синхронизации между устройствами — перенос через экспорт/импорт JSON.
- Автобэкап хранится в браузере на том же устройстве и не заменяет экспорт JSON.
- Уведомления локальные: на iPhone работают у установленной PWA, пока система не
  выгрузила приложение; серверных push-напоминаний пока нет.
- AI-тренер работает только онлайн, может ошибаться и не заменяет врача.
- Цены/рекорды считаются по введённым данным; база упражнений не является
  медицинской рекомендацией.
